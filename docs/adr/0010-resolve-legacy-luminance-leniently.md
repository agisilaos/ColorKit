# Resolve legacy luminance leniently

`relativeLuminance()` will resolve its input the way `wcagRelativeLuminance()` does, through `UIColor`/`NSColor` for the current appearance, while `relativeLuminanceValue()` continues to resolve strictly through a resolved sRGBA snapshot. Resolving the non-optional accessor strictly reported zero for every named SwiftUI color, because `Color.blue`, `.orange`, `.green`, `.red`, and `.gray` carry no `cgColor`; that made `contrastRatio(with:)` report 1:1 against black and 21:1 against white, and made `isDarkColor()` select the weaker endpoint for all of them, contradicting the guarantee recorded in [ADR 0007](0007-classify-dark-colors-at-equal-contrast.md). The two accessors therefore differ deliberately: the non-optional one answers for the appearance in effect, and the optional one reports no value rather than resolving a color whose components depend on context.
