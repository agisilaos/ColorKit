# Use the Machado model for dichromacy simulation

ColorKit will simulate protanopia, deuteranopia, and tritanopia with the full-severity matrices from the Machado–Oliveira–Fernandes physiologically based model, applied in linear sRGB. This gives fixed-color transformations a published, reproducible basis; achromatopsia is excluded because an ordinary grayscale conversion is not established by that model and would overstate ColorKit's support.
